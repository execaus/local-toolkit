# Local Toolkit 0.3.0

- The app now uses the visible name Local Toolkit. Its existing internal bundle identity and package filename are retained so previously installed copies can receive the update.
- Wake, screen-wake, and time-change notifications are forwarded safely to the main actor. Idle-sleep assertions are renewed after wake.
- Local diagnostics now record state transitions, periodic heartbeats, and whether the prior session ended without a normal termination marker. Logs contain no recorded audio or recognized text.
- Settings show when launch at login is off. This option controls startup after login; it does not restart a process after an unexpected exit.

Dictation and idle-sleep control remain local. Update checks contact GitHub only when requested. The build still uses an ad hoc macOS signature, so an operating-system permission prompt may recur after installation until a stable signing identity is configured.
